Vou explicar os regex (expressões regulares) usados no código: 1. /\D/g - Remove tudo que não é dígito javascriptvalor = valor.replace(/\D/g, ''); Breakdown: / / - delimitadores da expressão regular \D - representa qualquer caractere que NÃO seja dígito (0-9) É o oposto de \d (que representa dígitos) g - flag global, substitui todas as ocorrências, não apenas a primeira Exemplo: javascript"12345-678".replace(/\D/g, '') // resultado: "12345678" "abc123def456".replace(/\D/g, '') // resultado: "123456" Uso no código: Limpa o CEP removendo hífens, espaços e qualquer outro caractere que não seja número. 2. /^(\d{5})(\d)/ - Captura grupos para formatação javascriptvalor = valor.replace(/^(\d{5})(\d)/, '$1-$2'); Breakdown: ^ - início da string (\d{5}) - grupo 1: captura exatamente 5 dígitos \d - um dígito (0-9) {5} - quantificador, exatamente 5 vezes () - parênteses criam um grupo de captura (\d) - grupo 2: captura 1 dígito $1-$2 - substitui pelos grupos capturados com hífen entre eles $1 - conteúdo do grupo 1 (primeiros 5 dígitos) - - hífen literal $2 - conteúdo do grupo 2 (6º dígito) Exemplo passo a passo: javascript// Entrada: "123456" // Grupo 1 captura: "12345" // Grupo 2 captura: "6" // Resultado: "12345-6" "123456".replace(/^(\d{5})(\d)/, '$1-$2') // "12345-6" "12345678".replace(/^(\d{5})(\d)/, '$1-$2') // "12345-678" Uso no código: Formata o CEP automaticamente adicionando o hífen após o 5º dígito enquanto o usuário digita. 📚 Conceitos Importantes: Metacaracteres comuns: \d - dígito [0-9] \D - não-dígito \w - palavra [a-zA-Z0-9_] \W - não-palavra \s - espaço em branco ^ - início da string $ - fim da string . - qualquer caractere Quantificadores: {n} - exatamente n vezes {n,} - n ou mais vezes {n,m} - entre n e m vezes + - 1 ou mais vezes * - 0 ou mais vezes ? - 0 ou 1 vez Flags: g - global (todas as ocorrências) i - case insensitive m - multiline 🎯 Exemplos práticos adicionais: javascript// Validar email const emailRegex = /^[\w.-]+@[\w.-]+\.\w+$/; // Validar telefone brasileiro const telefoneRegex = /^\(?(\d{2})\)?\s?9?\d{4}-?\d{4}$/; // Extrair números de uma string "Preço: R$ 1.234,56".match(/\d+/g); // ["1", "234", "56"] // Remover espaços extras "texto com espaços".replace(/\s+/g, ' '); // "texto com espaços" Buscador de CEP
